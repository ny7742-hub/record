# 📄 PDF 탭 — 합치기 · 나누기 · 쓰기

2026-10-28 영업2팀("pdf파일에 변환, 쓰기 기능"). 범위는 사용자에게 물어 정했다: **PDF 합치기·나누기** + **글자 · 서명·도장 · 펜·형광펜**
+ (같은 날 추가 요청) **PDF 양식 칸 채우기**, 새 탭. 탭 버튼은 `🎨 힉스필드` 다음(`tab-pdf` / `page-pdf`, `pdfRender`), 홈 바로가기 칩 `PDF 합치기·쓰기`(맨 끝, `tab:"pdf"`).
엑셀·이미지 → PDF, PDF → 이미지·엑셀 변환은 이번에 넣지 않았다.

## 파일은 브라우저 안에서만
- 올린 PDF는 메모리(`pdfSrcs`·`pdfPages`)에만 있다 — 서버·Firebase로 보내지 않고, 새로고침하면 비워진다.
- 보기·미리보기: pdf.js 3.11.174(이미 쓰던 것). 저장: **pdf-lib 1.17.1** — 처음 저장할 때만 cdnjs에서 불러온다(`_pdfLib`, `PDF_LIB_URL`).
- 밖에서 받는 것: pdf-lib·fontkit(`@pdf-lib/fontkit` 1.1.1, jsDelivr)·한글 글꼴(나눔고딕 TTF, jsDelivr의 google/fonts 고정 커밋, 약 2MB) — 파일을 보내는 게 아니라 받기만 한다.
- 서명·도장 이미지만 이 브라우저 localStorage `pdfMarks`에 기억한다(최근 12개, 칸이 모자라면 기억 없이 그대로 쓴다).
- pdf.js 미리보기는 requestAnimationFrame으로 그려서 **브라우저 탭이 숨겨져 있으면 불러오기가 멈췄다가** 다시 보이면 이어진다.

## 쪽 목록 (합치기·나누기)
- PDF를 여러 개 올리면(칸 클릭·끌어 놓기 — 쪽 목록 위에 떨어뜨려도 됨) 쪽이 차례로 이어진다. 암호 걸린 PDF는 못 연다(메시지에 표시).
- 쪽 카드: 끌어서 순서 바꾸기(+ `◀ ▶`, 휴대폰은 이걸로) · `⟲ ⟳` 90° 돌리기 · `✏` 쓰기 · `✕` 빼기 · 체크로 고르기. `✏n` = 쓴 것 개수, `📝n` = 양식 칸 개수(`✓` = 채움).
- 저장(파일 이름은 첫 쪽 원본 이름 기준):
  - `💾 전체를 한 PDF로` — 지금 순서 그대로 한 파일(`_합침`, 원본 하나면 `_수정`).
  - `✂ 고른 쪽만 한 PDF로` — 체크한 쪽(`_2-3,5`).
  - `나누기` 칸 `1-3, 4-6, 7` → 묶음마다 파일 하나(`_1-3`). `~`·공백도 받는다. 쪽 번호는 **지금 목록 순서** 기준.
  - `📑 쪽마다 따로` — 쪽마다 파일 하나(15개 넘으면 확인). 여러 파일은 0.4초 간격으로 받는다(브라우저가 여러 파일 받기를 물으면 허용).
- 원본 쪽은 pdf-lib `copyPages`로 그대로 옮긴다 — 글자·선·링크가 이미지로 바뀌지 않는다.

## ✏ 쓰기 창 (`pdfEd`)
- 쪽 미리보기를 누르면 열린다. `◀ ▶`(PageUp/PageDown)로 쪽 이동, `－ 맞춤 ＋` 확대, `✔ 완료`(Esc).
- 도구: `📝 양식 칸`(아래) · `🖱 고르기`(옮기기 · 오른쪽 아래 □로 크기 · 글자는 두 번 눌러 고치기) · `T 글자`(Enter 끝, Shift+Enter 줄바꿈) ·
  `✍ 서명·도장`(그리거나 이미지 올리기, `흰 바탕 투명하게`로 스캔한 도장 바탕 지우기) · `✒ 펜` · `🖍 형광펜`(Shift = 곧은 줄) · `▭ 네모` · `⬜ 가리기`(흰 네모 — 위에 글자를 쓰면 고친 것처럼).
- 색·굵기/글자 크기(pt — 막대 또는 **숫자 칸**, 1~200) 칸이 바꾸는 것: **입력 중인 글자**(입력칸이 열린 채 크기·색 칸으로 옮겨 가도 닫히지 않는다 — Enter·막대 놓기·색 고르기 끝에 입력칸으로 돌아감)
  → 고른 것(어느 도구든, 글자는 확정하면 자동으로 골라진다) → 없으면 그 도구의 다음 값. 2026-10-28 "글자를 다 입력하고 전체 잡고 크기 변경" 요청.
- 새 글자는 **누른 자리가 첫 줄 가운데**에 온다(I자 커서 가운데 = 글자 줄 가운데, 예전엔 누른 자리가 글자 위쪽 끝이라 아래로 밀려 보였다).
- `↶ 되돌리기`(Ctrl+Z, 쪽마다 40번) · `🗑 고른 것 지우기`(Delete).

## 📝 양식 칸 채우기 (PDF 안 입력칸, AcroForm)
- 올릴 때 pdf.js `getAnnotations`로 위젯(글자·여러 줄·체크·라디오·목록)을 찾는다(`_pdfFields`, 서명·버튼 칸은 뺌). 값은 원본 파일마다 `src.vals[칸 이름]`(처음 값 `src.orig`) — 같은 이름 칸은 여러 자리·여러 쪽이 같이 바뀐다.
- 양식 칸이 있는 쪽을 열면 `📝 양식 칸` 도구로 시작하고, 칸 자리에 파란 입력칸을 띄운다(`_pdfFormUi`, 돌린 쪽도 자리 맞춤). 읽기 전용 칸은 막힘.
- 저장: **값을 바꾼 칸만** 원래 칸을 빼고(`_pdfFormStrip`, pdf-lib `removeField`) 값을 직접 그려 넣는다 — 저장한 PDF에서 그 칸은 더는 입력칸이 아니다(안 바꾼 칸은 원래대로). pdf-lib의 칸 모양 만들기는 Helvetica라 한글을 못 써서 이렇게 했다.
  글자 칸: 칸 높이에 맞춘 크기(한 줄은 넘치면 줄임, 여러 줄은 폭에 맞춰 줄바꿈, 정렬 따름) · 체크는 ✓ · 라디오는 ●.

## 쓴 것을 저장하는 방식
- **글자**(쓴 글자 + 양식 글자 칸)는 한글 글꼴을 PDF에 넣어 **PDF 글자(벡터)**로 쓴다(`_pdfTextItems` → `_pdfVecText`) — 확대해도 선명하고 복사·검색된다(2026-10-28 "화질이 별로"). 화면도 같은 글꼴(`PdfKR`)로 그려 자리·폭이 같다.
  - fontkit `subset:true`는 **한글 글자가 빠진다**(나눔고딕·Pretendard 둘 다 pdf.js로 확인) → 글꼴을 통째로 넣는다. 글자가 있는 PDF는 **약 0.75MB 커진다**(파일당 한 번).
  - 글꼴·fontkit을 못 받으면 예전처럼 PNG에 그린다(콘솔 경고).
- 나머지(서명·도장·펜·형광펜·네모·가리기·체크)는 쪽마다 **투명 PNG 한 장**(긴 변 약 3300점 ≈ 280dpi, `_pdfAnnPng`)으로 원본 쪽 위에 얹는다(`_pdfBuild`). 원본 내용은 그대로라 가리기는 **보이는 것만 가린다**(아래 글자는 PDF 안에 남아 복사·검색될 수 있음 — 민감한 내용 지우기 용도로 쓰지 말 것).
- 좌표: 쪽 = `{s, i, w, h(원래 방향 pt), r0 원본 /Rotate, rot 여기서 돌린 각도, anns}`. 쓴 것은 **쓸 때 보던 방향**(`a.r` = 그때 `rot`)의 pt 좌표로 둔다.
  다른 방향으로 그릴 때는 `_pdfM`(그리기)·`_pdfToFrame`(누른 점 → 쓴 것 좌표)로 돌린다 — 쓴 뒤에 쪽을 돌려도 같이 돈다.
- PNG는 원본 /Rotate가 적용된 방향이라, 쪽 좌표계로 넣을 때 `drawImage`의 `rotate = r0`와 시작점을 cropBox 모서리로 맞춘다(pdf-lib rotate는 (x,y) 기준 반시계).
  글자는 쓴 방향 좌표 → 원래 방향(`_pdfM`) → pdf.js 뷰포트 `convertToPdfPoint`로 PDF 좌표·줄 방향 각도를 구해 `drawText(rotate)`. 마지막에 `setRotation(r0 + rot)`. 원본 /Rotate 0·90, 여기서 90·270 돌린 쪽은 저장 결과를 다시 그려 확인했다(2026-10-28, 원본 180·270은 같은 식이지만 실제 파일로는 아직 못 봄).
