# 마진계산 · 공문 · 손익계산서

`CLAUDE.md`에서 분리한 상세 문서. 내용은 그대로이고 위치만 옮겼다.

- 공문 작성 (`💰 마진계산 · 공문` 탭 아래쪽 — **마진계산과 한 화면**이다, 2026-09 영업2팀): 코스트코(**바이어 D26·D31 둘로 나뉜다**)와 백화점 공문을 한자리에서 만든다.
  위쪽 버튼으로 `코스트코 D26` · `코스트코 D31` · `백화점`을 고르고, 고른 값이 공문 `수신`에 그대로 들어간다.
  **행사약정서(KO COUPON CONTRACT) PDF를 올리면 공문이 저절로 채워진다**(`docLoadContract`) —
  약정서 한 장에 공문에 필요한 값이 다 있다:
  `Dept / Buyer`(26·31) → 수신 · `Item #`(6자리) · `Item Description`(영문 상품명) ·
  `Start Date - End Date` → 기간(`marginDB.period`) · `Coupon Value` · `Vendor Fund` · `Costco Fund` ·
  Inline/Online(금액이 붙은 쪽) → 판매처. 업로드 칸은 공문 카드 맨 위에 있다(`.doc-ct-drop`).
  **마진계산 행을 고르지 않아도 약정서 값으로 공문이 완성된다**(`_mgCtItems`가 `contract.fromContract`로 물러선다) —
  예전에는 마진계산 표에서 행을 골라야만 `3. 내용`이 채워졌다.
  제목은 품목이 하나면 상품코드를 앞에 붙인다(`온라인 상품 696151 WHITE SANDS LONG UMBRELLA 행사 진행건`) —
  한글 공문 원본 표기와 같다.

- **제안 상품 손익 계산서** (`💰 마진계산 · 공문` 탭, 행사 마진 표 바로 아래 · 2026-09 영업2팀) — **코스트코 전용이 아니다**(거래처 공용).
  `거래처` 칸(목록 `cpChList`: 코스트코·홈쇼핑·백화점 …, 직접 입력 가능)이 있고 제목·파일명에 `코스트코`를 쓰지 않는다
  (거래처가 하나면 파일명 앞에 붙인다: `홈쇼핑 제안상품 손익계산서(0917)`).
  **프로모션은 `프로모션(원)` + `프로모션%`(제안가 대비) 두 칸** — 개당 부담 = 원÷(비용 VAT) + 제안가×%÷1.1, 행사수량에 곱한다. **행사수량을 비우면 순판매수량(발주−반품) 전체**에 건다 — 예전엔 비우면 0이라 프로모션%를 넣어도 결과가 안 바뀌었다(영업2팀 문의). 0을 적으면 0.
  칸 이름은 **`제안가`**다(2026-09-21 영업2팀 — 예전 이름 `소비자가`). 필드 키는 `retail` 그대로라 저장된 자료는 그대로 쓴다.
  **수수료율은 꼭 적는다** — 비어 있으면 칸을 노랗게(`필수`) 표시하고, PDF에도 `수수료율 미기재`로 찍는다.
  **0%도 적은 것**으로 본다(`_cpFeeMode`: 값이 있고 제안가가 있으면 수수료 방식 → 0%면 공급가 = 제안가).
  수수료율·프로모션%를 적었는데 제안가가 없으면 제안가 칸을 노랗게 표시한다.

- (예전 이름: 코스트코 제안 상품 손익 계산서) 행사 마진 계산서
  (`판매가 − 수수료 − 당사부담 − 원가 − 택배비`, VAT 미조정)와 **별개**다. 코스트코가 사가는 **공급가**에서 출발한다.
  **이익금액은 VAT 포함이 기본**(2026-09-18 영업2팀 지정, 상단 `이익금액` 선택 `ccPropDB.basis`: `in`(기본)/`ex`) —
  계산은 아래처럼 VAT 제외로 한 뒤 금액만 ×1.1(`_cpK`) 한다. 금액이 모두 1차식이라 이익률·공헌이익률·마진율은 기준과 무관하다.
  화면·PDF·보고 문구의 `VAT 포함/제외` 표기는 `_cpBasisTxt()`를 따른다.
  팀 공유 `ccPropDB`(`ws/ccProp`), `cpRender`/`_cpCalc`/`cpExport`. 내부 계산은 모든 금액을 **VAT 제외로 맞춘다** —
  공급가는 행마다 포함/별도 선택, 비용(원가·패키지·물류·기타·프로모션·반품손실·고정비)은 `비용을 VAT 포함으로 입력` 체크 시 전부 ÷1.1.
  개당 공헌이익 = 실질공급가 − (원가+패키지+물류+기타). 반품분(발주×반품률)은 매출 없음·제품은 재고 복귀로 보고
  패키지·물류·기타 + `반품손실`만 손실로 잡는다. **프로모션 부담은 `행사수량`에 곱한다**(비우면 반품을 뺀 판매수량 전체 — 반품분까지 곱하면 과대 차감).
  최종 예상이익 = 순판매수량×공헌이익 − 반품손실 − 행사수량×프로모션 − 고정비, 이익률은 순매출 대비.
  **한 상품 = 두 줄**(영업2팀 요청): 위 줄은 입력 칸, 바로 아래 노란 줄에 계산 결과(`CP_OUT`, 칩 모양·줄바꿈 허용)를 모은다 —
  한 줄에 다 늘어놓으면 가로로 끌어야 최종 이익이 보였다. 입력 칸 폭(`CP_FIELDS` 세 번째 값)은 1700px 화면에서 스크롤 없이 들어가게 줄여 뒀다.
  제안가는 참고(코스트코 마진율 표시)일 뿐 계산에 안 쓴다. 입력 중에는 표를 다시 그리지 않고 계산 칸만 바꾼다(`_cpPaintRow`) —
  다시 그리면 입력 포커스가 날아간다. 원격 갱신도 입력 중이면 건너뛴다(`_cpEditing`).
  예시 검증: 공급가 22,000(VAT포함)·원가 8,500·패키지 1,500·물류 500·기타 300·프로모션 1,000×3,000개 → 개당 8,200 · 41% · 2,460만원.
  **포장비**(`wrap`, 포장·세트 조립 작업비) 칸은 패키지(자재비)와 따로 둔다 — 변동원가와 반품 손실에 함께 들어간다.
  **세트 상품**: 상품명 앞 `단품/세트` 버튼(`cpToggleSet`). 세트는 `items:[{name,cnt,cost}]`로 구성품을 적고
  **제품원가 = Σ(개입수×원가)**(`_cpSetCost`, 원가 칸은 읽기 전용), 공급가·패키지·포장비·물류·발주수량은 세트 1개 기준.
  구성품 총 필요수량(개입수 합 × 발주 세트수)을 하위 줄에 보여준다. 구성품명을 적으면 원가를 상품리스트 사전원가로 채운다.
  **금액은 VAT 포함으로 적는 것이 기본**(영업2팀 지정) — 새 행은 공급가 `포함`, `비용을 VAT 포함으로 입력`도 기본 켜짐.
  **상품명만 넣으면 TAG가·사전원가가 자동으로 들어간다**(`_cpFindProduct`) — 상품데이터(`DB`)를 상품코드별로 묶어(TAG가·사전원가는 가장 많은 값)
  `[브랜드]`·시즌(`26SS`)·`화이트샌즈`를 뗀 이름에 낱말이 모두 든 상품을 찾는다. 여럿이면 이름이 똑같은 것, 그래도 여럿이면 안 넣는다
  (`루노아`는 2개 → 노랑, `우양산 루노아`로 좁히면 초록). 못 찾으면 코스트코 상품등록부(`ccMatchProd`)로 한 번 더 보고,
  TAG가가 0인 코스트코 단독상품은 `CC_ONLY_PRICE`를 쓴다. 입력칸에 상품명 목록(`datalist#cpProdList`)이 붙는다.
  **자동값만 바꾸고 직접 고친 값은 그대로 둔다** — 마지막 자동값을 `auto`에 기억해(`_cpAutoSet`) 칸 값이 그와 같거나 빈 경우만 덮는다.
  세트는 구성품마다 TAG가·원가가 채워지고, 세트 TAG가(`_cpSetTag`)·원가는 개입수를 곱해 더한 합계(읽기 전용).
  **수수료율**(`fee`, %): 넣으면 수수료 방식 — 공급가 = 제안가(VAT 포함) × (1 − 수수료율)로 자동 계산해 공급가 칸을 잠그고
  (`_cpFeeMode`·`_cpSyncSupply`, 공급가 VAT 선택도 잠금), `수수료` 계산 칸에 제안가×수수료율÷1.1을 보여준다.
  비우면 예전처럼 공급가를 직접 적는다.
  **반대 방향도 된다**(2026-09-22 영업2팀) — 수수료율을 비워 두고 **제안가와 공급가를 적으면 수수료율을 역산해 채운다**
  (`_cpFeeFromSupply`: `1 − 공급가(VAT 포함) ÷ 제안가`, 소수 첫째 자리). 역산된 값은 `feeAuto`로 표시해
  **공급가 칸을 잠그지 않는다** — 잠그면 사람이 적은 공급가가 반올림된 수수료율로 되돌아가 조금씩 달라진다.
  `_cpFeeMode`도 `feeAuto`면 false다. 수수료율을 직접 적는 순간 `feeAuto`가 풀리고 그 값이 우선이 된다.
  수수료 금액은 두 방향 모두 계산 칸에 나온다(역산일 때는 `제안가÷1.1 − 실질공급가`).
  검증: 제안가 59,000 · 공급가 33,630 → 수수료율 43% · 수수료 25,370 · 최종이익 10,970 · 이익률 32.6%(정방향과 같은 값). 수수료율 칸의 흐린 예시값은 행사 마진 계산서의 수수료율(`marginDB.fee`).
  **📝 보고 문구**(엑셀 다운로드 옆, `cpBuildReport`/`cpToggleReport`/`cpCopyReport`): 상품마다
  `[거래처] 상품명(세트 구성)` → 가격(TAG가·판매가·수수료·공급가) → 원가+부대비용 → 개당 공헌이익 → 조건(발주·반품·프로모션·고정비)
  → 최종 예상이익 순으로 적고, 상품이 둘 이상이면 합계 줄, 끝에 VAT 기준 안내를 붙인다. 표를 고치면 바로 갱신하되
  문구 칸을 직접 고치는 중(포커스)이면 덮지 않는다(`_cpRefreshReport`). 적자면 `※ 적자`.
  **이 계산서에는 공문이 없다**(영업2팀 지정) — 문서는 `📥 엑셀 다운로드`(`cpExport`)·`📄 PDF 다운로드`(`cpExportPdf`)와 복사용 보고 문구뿐.
  PDF는 화면 표와 따로 인쇄용 문서(`_cpDocHtml`, A4 가로, 12행씩 쪽 나눔, 마지막 쪽에 합계·계산 기준)를 그려 html2canvas로 뜬다.

- 마진계산 → 코스트코 행사 공문 (같은 탭 아래쪽 공문 화면):
  엔에이치그룹 공문 **A4 1장**을 PDF로 만든다(html2canvas + jsPDF, 아난티 명세서와 같은 방식).
  마진계산 표와 공문은 **한 탭**이다 — 표에서 금액을 보고 바로 아래에서 공문을 만든다.
  **금액은 마진계산 표에서 VAT 제외로 자동 산출** — `쿠폰=(판매가−쿠폰적용가)÷1.1`,
  `Vendor fund=당사부담금÷1.1`, `Costco Fund=코스트코부담÷1.1`. 상품코드가 그대로 공문 내용의 품번이 된다.
  **행사기간은 따로 입력받지 않고 맨 위 `행사기간` 칸(`marginDB.period`)을 파싱해서 쓴다**(`_mgCtPeriod`) —
  `6/8~6/21`·`9/14 ~ 9/27`·`2026.09.14~2026.09.27`·`2026년 9월 14일 ~ …` 형태를 읽고,
  연도를 안 적으면 올해로 보며 종료가 시작보다 앞서면(연말~연초) 종료만 다음 해로 넘긴다.
  수신은 `코스트코 상품본부(D31)`·`(D26)` 중 선택, 판매처는 `코스트코 인라인`·`온라인` 중 선택이고
  **판매처가 공문 제목의 `인라인/온라인 상품`을 정한다**. 문서번호는 발송일자 기준 `NH-MMDD-01` 자동(직접 적으면 우선).
  상품이 여러 건이면 행마다 `공문 표기명`을 적을 수 있고, 비우면 제목의 영문 상품명을 쓴다.
  직인은 이미지 업로드 시 자동 날인되며 `localStorage.mgSealImg`에만 둔다(용량·개인도장이라 팀 공유 안 함).
  직인 등록·변경·삭제는 **공문 카드 머리에 늘 보이게** 둔다(`mgRenderSealBar`) — 입력값을 접어 두면 못 찾는다.
  직인은 **이름 오른쪽 옆자리**에 찍는다 — 직인이 있으면 그 폭(74px+여백)만큼 서명란 오른쪽을 비우고
  그 빈자리에 놓는다. 이름 위에 겹쳐 놓으면 `대 표 이 사 나경화`가 가려진다.
  공문 글꼴 목록에 **고정폭(BatangChe)을 넣지 말 것** — 바탕이 없는 PC에서 그걸로 그려지면
  영문·괄호·마침표까지 한글 한 칸 폭을 차지해 `NH -0910 -01`처럼 낱말이 벌어진다.
  공문에 적는 영문 상품명은 **브랜드를 붙여 쓴다**(`_mgCtEnName`: `WHITE SANDS` → `WHITESANDS`) —
  약정서에는 띄어 오지만 한글 공문 원본은 `WhiteSands`로 붙여 쓴다. 검토 요청 문구는 그대로 띄어 쓴다.
  **검토 요청 문구**(`mgBuildNote`)는 2026-09 영업2팀 지정 형식이다 —
  `코스트코 <영문상품명>(<한글상품명>) 상품의 매출 활성화를 위해 …`로 시작하고
  행사기간·판매가·쿠폰금액(VAT+)·원가·수수료·마진 순으로 적으며 **확인 요청이 맨 끝**에 온다.
  영문명은 행사약정서에서 읽은 것을 쓰고, 택배비는 값이 있을 때만, 창고재고 줄은 넣지 않는다.
  **마진 5,000원 이하 경고(※)는 문구에 넣지 않는다** — 그대로 붙여넣어 보내는 글이라 화면에만 띄운다.
  KO COUPON CONTRACT(코스트코 쿠폰 계약서) 페이지는 만들지 않는다 — 그 양식은 코스트코 것을 직접 작성한다.
