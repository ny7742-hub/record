# 반품등록

`CLAUDE.md`에서 분리한 상세 문서. 내용은 그대로이고 위치만 옮겼다.

- 반품등록 탭에는 **홈쇼핑 반품등록**과 **코스트코 반품등록** 두 섹션이 있고, 둘 다 4단계다
  (1 반품리스트 열기 · 2 붙여넣기 · 3 코드매칭 · 4 사입반품양식 다운로드).
  1단계 링크는 같은 시트의 다른 탭을 연다 — 홈쇼핑은 `gid=36451127`, 코스트코는 `gid=0`(온라인).
  코스트코 1단계 안내는 **온라인 탭에서 `처리완료·입고일·처리일·해체일`이 모두 적힌 내역을
  `온라인(완료)` 시트로 옮긴 뒤 2단계에 붙여넣으라**고 적어 둔다.
  **색(초록/연두) 이야기는 안내에서 뺐다**(2026-09-23) — 등록 조건에서 음영을 뺐는데 안내에만 남아 있으면 헷갈린다.
  홈쇼핑 쪽에는 **5단계 시트 정리** 안내가 더 있다 —
  ① 홈쇼핑 → `온라인(완료)`에 해당 건 복사 후 홈쇼핑에서 삭제 ② 불량건은 창고간 이동
  ③ **세일즈매니지먼트에 반품 데이터 업로드**(바로가기 `https://wssales.pages.dev/#data` — 코스트코 7단계 ④도 같다).
  세일즈매니지먼트는 탭을 바꿔도 주소가 안 바뀌고 주소로 탭을 고르지도 않아서, **`#data`는 그쪽이 주소의 `#탭이름`을 읽도록 고쳐야 먹힌다**
  (그 전에는 대시보드가 열릴 뿐 문제는 없다). 그쪽 `setTab` 바인딩 뒤에 `location.hash`를 읽어 `setTab(t)` 하는 몇 줄이면 된다.
  **1단계 `📥 시트에서 바로 불러오기`**(2026-09 영업2팀, `hsrLoadSheet`/`ccrLoadSheet`/`_retSheetRows`): 반품리스트 시트
  (`RET_SHEET_ID`, 홈쇼핑 `gid=36451127` · 온라인 `gid=0`)가 **링크 공유(보기)** 라 gviz CSV(`/gviz/tq?tqx=out:csv&gid=`)를
  브라우저에서 바로 읽는다(CORS 허용). 읽자마자 **수취인·연락처·주소 열을 비우고**, 칸 안의 줄바꿈·탭을 지워
  붙여넣기와 같은 경로(`_hsrProcessRows` / `ccrPasteRows`)로 넘긴다 — 파싱 규칙이 하나로 유지된다.
  불러오기는 **표를 비우고 새로** 채운다(두 번 눌러도 중복 안 됨, 표에 행이 있으면 확인).
  **홈쇼핑 탭도 `결과 = 처리완료` + 입고일·처리일·해체일이 모두 적힌 줄만** 불러온다(2026-09-18 영업2팀 지정, 머리글로 열을 찾음).
  제외 사유별 건수(결과 빈칸·처리보류·해체일 없음 …)를 버튼 아래에 적는다. **붙여넣기도 같은 조건**(`_hsrReady`/`_hsrWhyNot`) — 머리글이 있으면 `결과`·`처리일` 칸도 읽고(`결과`가 두 번 나오면 첫 칸),
  머리글이 없으면 `_ccrMapRow`의 status·proc를 쓴다. 붙여넣은 표에 결과 칸이 아예 없으면 상태는 안 보고 날짜 3개만 본다.
  조건 미충족 줄은 회색 + 툴팁에 이유.
  온라인 탭은 모든 온라인몰 반품이 섞여 있어 **쇼핑몰에 `코스트코`가 든 · 상태 `처리완료`** 인 줄만 가져온다
  (수동 흐름의 '초록색 처리완료 건'과 같은 기준 — 셀 색은 CSV로 못 읽는다).
  시트를 비공개로 바꾸면 gviz가 로그인 HTML을 돌려주므로 그때는 안내 알림을 띄운다 → 그 경우 Apps Script 웹앱으로 바꿔야 한다.
  코스트코 쪽은 CX팀_반품리스트(구글 시트) **`온라인` 탭**에서 `처리상태 ~ 결제가`(15열)를 그대로 붙여넣는다
  **열 위치는 고정하지 않고 내용으로 찾는다**(`_ccrMapRow`) — 복사 범위가 한 칸만 밀려도
  고정 위치로는 상품명 자리가 어긋나 전부 미매칭이 됐다.
  상품명은 **점수로 고른다** — `화이트샌즈`가 든 칸 중 `[`로 시작하고 바로 뒤가 수량(작은 숫자)인 칸이 이긴다.
  가장 긴 칸을 쓰면 `333165084-1 #694099-BK 화이트샌즈 … 합포장하셨다며 전달 요청` 같은 **비고 칸**을 집어
  상품명이 통째로 어긋난다(`#`·`합포장`·`요청`·주문번호가 든 칸은 감점).
  수량·결제가는 상품명 뒤 첫 숫자칸과 다음 칸,
  상태는 `CCR_STATES` 중 하나가 든 칸, 날짜는 상품명 앞의 날짜칸들(마지막이 해체일)에서 찾는다.
  **`처리보류`·`확인요청`·`출고예정`은 제외**한다(`CCR_SKIP`) — 아직 끝난 건이 아니다.
  상품명 → 상품컬러코드는 `_hsFindMatchFromDefaultData`로 찾고, 공급가 = 결제가 ÷ 수량.
  결제가가 `미매핑`처럼 숫자가 아니면 비워 두고 표에서 직접 채운다.
  **반품일자 = 물류입고일**(매뉴얼 `반품 입력_이미지 매뉴얼` 기준), 매장·창고코드는 4단계 입력칸(기본 `COSO`/`NH`).
  **등록 조건 = 처리완료 + 입고일·처리일·해체일 모두**(2026-09-23 영업2팀 — **민트색 음영은 빼기로 했다**)(2026-09-18 영업2팀 재지정, `_ccrReady`/`_ccrWhyNot`) —
  하나라도 빠지면 회색으로 두고 빼며 줄 툴팁에 이유를 적는다. 정렬·반품일자는 여전히 물류입고일(`_ccrSortByIn`).
  (한때 '입고일만 있으면 등록'으로 풀었다가 되돌렸다 — 해체일까지 끝난 건만 등록한다.)
  **민트색 음영은 더 이상 보지 않는다**(2026-09-23 영업2팀) — 셀 색은 Sheets API가 켜져 있어야 읽히는데 실제로는 403으로 못 읽는 때가 많았다.
  이제 `ccrLoadSheet`는 Sheets API를 아예 부르지 않고 **처리완료 + 날짜 3개**로만 고른다(`_ccrWhyNot`).
  (예전 방식: 음영은 CSV에 없어서 **Sheets API v4**(`_retSheetShades`, Firebase 프로젝트 API 키)로 A열 배경색을 읽는다 —   연두·민트 계열(`_retIsMint`: 초록이 빨강·파랑보다 0.04 이상 큼, 시트 실제 색 `#d9ead3`)이면 음영 있음.   그 프로젝트(702948407363)에서 **Google Sheets API가 꺼져 있으면 403**이라 음영은 '미확인'(`shade` undefined)으로 두고   상태·날짜로만 고르며 `⚠ 민트색 음영은 확인 못 함`을 띄운다. CSV 줄과 API 줄은 A열 글자로 대조해 어긋나면 미확인.)
  2026-09-18 기준 처리완료 행은 모두 민트색이고, 날짜 3개가 다 찬 건 4건이었다(htmlview로 확인).
  날짜는 **쇼핑몰 바로 앞 세 칸**(입고일·처리일·해체일)을 자리로 읽는다 — 날짜가 든 칸만 모으면
  해체일이 비었을 때 처리일을 해체일로 잘못 읽는다.
  **날짜 형식은 `8/21(금)` 말고 `08월 13일`·`2026년 8월 13일`도 읽는다**(`_hsrParseDate`·`_hsrYearGuess`, 2026-09-23) —
  시트의 입고일·처리일이 `08월 13일` 형식으로 바뀌면서 **등록 대상이 0건**이 됐었다(해체일만 `8/21(금)`이라 읽혔다).
  연도를 안 적으면 올해로 보되 오늘보다 6개월 이상 미래면 작년으로 본다.
  4단계 다운로드에 한 건도 안 나오면 **사유별 건수**를 알려 준다(예전엔 "입고일이 없습니다"로만 떠서 원인을 알 수 없었다).
  단계는 7단계 — 5 플레이엠디 등록(`[EX]사입매장출고반품등록`), 6 불량건 창고이동, 7 시트 정리.
  시트 맨 뒤 물류답변이 `TRUE`면 표의 `불량` 칸이 자동으로 켜지고(직접 체크·해제 가능),
  6단계 `📥 창고간이동 다운로드`가 **불량 건만** 창고이동 양식(8열)으로 내려준다
  (반품창고 `NH` → 입고창고 `BAD`, 상품코드 칸에 상품컬러코드, 이동일자 = 물류입고일).
  6단계는 플레이엠디 `[EX]창고입고반품이동등록`에 **작업구분 `(M)창고간이동` · 파일형태 `바코드`**로 올린다.
  수취인·연락처·주소는 읽지도 저장하지도 않는다.
  **홈쇼핑 반품등록도 같은 `_ccrMapRow`를 쓴다**(머리글 없이 붙여넣은 경우) — 예전에는 고정 위치(`prod:11`)로
  읽어서, 반품리스트처럼 앞에 `처리상태` 열이 하나 더 붙으면 주소를 상품명으로 읽어 코드매칭이 전부 실패했다.
  쇼핑몰(채널)은 반품매장코드를 정하는 값이라 `코스트코|홈쇼핑|면세|GS|CJ|SSG…` 키워드로 넓게 잡는다.
