## ↩ 매장 반품(2026-10-12 영업2팀 "이카운트 매장 반품등록")
- 같은 탭 위 **`📦 매장 발주 / ↩ 매장 반품`** 전환(`ecKind`, `_ecKind`). 화면·버튼 문구는 `EC_TXT[ord|ret]`. 담는 중인 목록은 종류별로 따로(`_ecDrafts`).
- 저장 `ws/ecReturns/{id}`(id `er…`, 발주는 `ec…` — `_ecPut`이 id 앞글자로 경로를 고른다). 흐름은 발주와 같다: 매장 반품 요청 → 본사 승인(수량 조정·본사 추가) → 입고 처리.
  상태값은 발주와 같은 문자열을 쓰고 '출고'만 화면에서 **입고**로 보인다(`_ecStLab`).
- 담을 때 **불량** 체크 → 줄에 `bad:true`. 창고이동 엑셀(`이카운트_창고이동_반품_YYYYMMDD.xlsx`)은 **매장 창고 → NH**, 불량 줄은 **→ 불량창고**(`ecConfig.bad`, 기본 `BAD` — PlayMD 불량창고와 같은 코드).
  받는 창고가 다르므로 한 반품 안에서도 정상·불량을 전표(순서 번호)로 나눈다. 반품에는 도매발주서가 없다.
