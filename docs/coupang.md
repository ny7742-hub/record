## 자동으로 하려면 필요한 것(아직 없음)
- PO 발주서 원본('발주서 업로드 양식' 다운로드 파일) 실제 예시 — 칸 이름을 알아야 가공할 수 있다.
- 쿠팡 발주서 양식 파일(물류센터 이름 → 연락처·주소가 채워지는 표 포함).
- 코드매칭: 쿠팡바코드(8800…) → 상품컬러코드 표를 자비스가 읽을 수 있게(구글 시트 공유 또는 내보내기).
- 서플라이어 허브 두 계정 로그인을 자동화 PC 포탈 창에 해 두기(비밀번호는 다루지 않는다).
- 발주 확정 업로드 · 쉽먼트 일괄 등록은 되돌리기 어렵다 — 자동으로 하더라도 미리보기 뒤 사람이 누르게.
