# 🧊 3D 집기 탭 (`page-floor`, `renderFloorPage`)

예전 이름 `3D 평면도`(2026-10-13, 채팅에서 만들어 GitHub에 올림) → **2026-10-14 영업2팀 요청으로 `3D 집기`로 바꾸고 넓혔다**.
코드는 `index.html` `</body>` 바로 앞 별도 `<script>` 블록, 탭 버튼 `#tab-floor`, 페이지 `#page-floor`(`page-lossreport` 앞). `switchTab`에서 `renderFloorPage()`. **팀 공유**(2026-10-14 영업2팀): Firebase `ws/fx3d` — `cur`(현재 배치) · `plans`(저장한 배치) · `use`(체크·수량·사이즈) · `cus`(직접 추가·사진 집기) ·
`img/<키>`(사진 집기 그림) · `photo`(예상 팝업 자리 이미지) · `meta`(마지막 배치 수정 사람·시각, 화면 `#fpShare`). localStorage는 같은 키로 사본을 둔다.
'바로 자동 배치'·바닥 진하기(`jvFloorOpt`)만 각자. 쓰기는 모아서(배치 0.5초) 한 번에, 되돌아온 내 값은 건너뜀(`SH.last`), 남의 배치는 끄는 중이면 버리고 내 것을 올린다(마지막에 쓴 사람이 이긴다).
탭을 처음 열 때 공유본(`cur`)이 비어 있으면 이 브라우저 것을 올려 시작(`startShare`). localhost·승인 전 사용자는 공유 안 함(다른 탭과 같은 규칙, 3초마다 다시 봄).

- **화면 배치**(2026-10-14 영업2팀): 위 = ③ 평면도(1칸) · ④ 3D 보기(2칸, 높이 600px) / 아래 = ① 집기 목록(넓으면 여러 줄, `#fpUse` 그리드) · ② 예상 팝업 자리 이미지(오른쪽) / 맨 아래 수량 표.
  900px 이하에서는 모두 한 줄씩(3D 높이 420px). 규칙은 `#page-floor` 안 `<style>`의 `.fp-top`·`.fp-bottom`.
- 공간 가로×세로(mm)를 넣고 집기를 놓는다. 3D는 Three.js(cdnjs r128)를 탭을 열 때 불러온다.
- **① 집기 목록** — 집기마다 **그림**(3D 모양을 비스듬히 찍은 썸네일, `makeThumbs`) · **사이즈**(가로×깊이×높이 mm, 원형은 지름×높이 — 칸에서 바로 고침, `fpDim`) · **보유 수량** · 배치 수.
  체크한 집기만 평면도·자동 배치에 쓴다. 저장 `jvFloorUse`({on, qty, w, d, h}).
  기본 집기: 선반집기 이미지형 8 · 거울형 9 · 로고테이블 2 · 우양산 12(화이트샌즈 집기 목록 기준),
  카운터 1 · 스탠딩 거울 2 · **곡면 2단 진열대 (좌) 1 · (우) 1 · 원형 집기 4**(매장 사진으로 잡은 추정값 — `(추정)` 표시).
  곡면 진열대는 **좌·우가 따로 있는 집기**다(2026-10-14 영업2팀, `curveL`/`curveR`, `side`) — 좌 = 둥근 모서리가 왼쪽 앞, 우 = 오른쪽 앞. 좌우반전 버튼은 선반에만.
  예전 배치의 `curveTbl`(f=좌우반전)은 읽을 때 `curveL`/`curveR`로 바꾼다(`setState`). 곡면 진열대·원형 집기 위 모자 장식은 뺐다(집기만 보이게).
  썸네일: 곡면 (좌)는 왼쪽에서 찍는다(둥근 모서리가 보이게).
  **+ 집기 직접 추가**: 이름 · 사각/원형 · 가로×깊이×높이 · 수량 → `jvFloorCustom`(지우기 버튼 있음).
- **📷 사진으로 집기 만들기**(2026-10-14 영업2팀, `fpPfxPick`·`fpPfxCut`·`fpPfxAdd`): 집기 사진을 올리면 가장자리 색(채널별 중앙값)을 배경으로 보고
  가장자리에서 퍼져 나가며 지워(집기 안쪽의 같은 색은 남음) 집기만 오려 낸다(`배경 지우기` · `민감도`, 구분이 안 되면 사진 전체).
  오려 낸 세로/가로 비율 × 가로(mm) = 높이 자동(높이를 직접 고치면 그 값 유지). 모양: 사각(상자) · 원형(기둥) · 판넬(세워 둔 판, 깊이 50~300).
  3D는 오려 낸 사진을 앞·뒷면에 입히고(판넬은 양면 한 장, `alphaTest`) 몸통은 사진의 평균색 — **사진만으로 정확한 입체는 못 만든다**, 사이즈는 실측으로.
  오려 낸 그림은 긴 변 480px WebP(투명)로 `jvFloorImg_<키>`에 따로 저장(목록 JSON을 가볍게), 집기를 지우면 같이 지운다. 직접 추가 집기와 같은 `jvFloorCustom`에 `shape: pbox|pcyl|panel, img:true, col`.
- **② 예상 팝업 자리 이미지** — 올리면 긴 변 1600px JPEG로 줄여 `jvFloorPhoto`에 저장(새로고침해도 남음, 저장공간이 모자라면 그 세션만).
  `평면도·3D 바닥에 깔기`(`jvFloorOpt.photoFloor`)를 켜면 공간 가로×세로에 맞춰 늘려 깐다 — 몰 도면처럼 위에서 본 이미지일 때. 비스듬한 현장 사진은 끄고 참고로만 본다. 진하기 슬라이더.
- **자동 배치**(`fpAuto`) — `집기를 고르면 바로 자동 배치`(`jvFloorOpt.autoOn`, 기본 켬)가 켜져 있으면 체크·수량·사이즈·공간 크기를 바꿀 때마다 다시 배치한다.
  뒷줄 선반집기(이미지·거울형 번갈아) · 양옆 스탠딩 거울 · 가운데 줄(통로 900 뒤) · 앞 모서리 곡면 진열대(왼쪽 = (좌), 오른쪽 = (우)) · 앞 가운데 원형 집기(지그재그, 남으면 빈 자리).
  가운데 줄은 자리가 모자라면 **카운터 → 로고테이블 → 직접 추가 → 우양산** 순서로 남긴다(보유 12개인 우양산이 카운터를 밀어내지 않게), 놓는 순서는 로고테이블 · 직접 추가 · 우양산 · 카운터(오른쪽 끝).
  못 놓은 집기는 메시지에 '자리가 모자라 못 놓은 집기: …'로 적는다. 세로가 짧으면 곡면 진열대를 가운데 줄 양끝에 놓는다.
- **수동 이동** — 평면도에서 끌기(50mm 단위), **3D 화면에서 집기를 끌기**(바닥 평면에 레이캐스트, 빈 곳을 끌면 화면 회전, 빈 곳 클릭은 선택 해제),
  방향키(Shift 500mm) · R 회전 · Delete, 선택 칸의 회전 · 좌우반전(선반) · 복제 · 삭제 · 중심 X/Z 입력. 빨간색 = 겹침 또는 공간 밖.
  저장 배치를 불러오거나 `📷 샘플 매장 재현`을 누르면 그 배치를 지키려고 자동 배치를 끈다.
- **📷 샘플 매장 재현** — 2026-10-14 받은 매장 사진 4장 배치(6600×4600: 뒤 선반 3 · 로고테이블 2 + 카운터 · 거울 2 · 앞 곡면 (좌)·(우) · 좌대 4).
- **이미지 화질**(2026-10-14 영업2팀 "3D 이미지 저장 시 화질 최대로", `shot3d`): 화면 3D 칸(300px 남짓)을 그대로 저장하지 않고 같은 시점으로 따로 크게 다시 그린다 —
  가로 16:10 · 배경 밝은 회색(투명 X) · 카메라를 집기 한가운데로 맞추고 거리를 꽉 차게 → 그린 부분만 4% 여백으로 잘라 냄 → 잘린 가로가 3840보다 작으면 그만큼 더 크게(최대 5600, 그래픽카드 한도 안) 다시 그려 자른다.
  결과는 가로 약 3840px(4K). 곡면·원기둥은 분할을 늘려(64·72) 크게 봐도 각이 안 보이게. 끝나면 화면 칸 크기·시점으로 되돌린다.
  집기리스트 이미지는 전체를 2배(2480px)로 그리고 3D도 고해상도로, 집기 그림(썸네일)은 480×360으로 찍는다.
- **🖼 집기리스트 이미지**(`fpListPng`) — 3D 화면 + 체크한 집기의 그림 · 이름 · 사이즈 · 보유 · 배치 표를 1240px PNG 한 장으로 내려받는다. `🖼 3D 이미지 저장`은 3D 화면만.
- 저장·불러오기·삭제: 배치만(`jvFloorPlans` · 팀 공유 `ws/fx3d/plans`), 현재 배치는 `jvFloorCur`(공유 `ws/fx3d/cur`)에 자동 저장.
- 좌표: x=오른쪽, z=아래(앞쪽 통로), 집기 중심 mm. rot 0=앞면 아래, 90=오른쪽, 180=위, 270=왼쪽.
- 3D 렌더러는 `preserveDrawingBuffer:true`(리스트 이미지에 화면을 그대로 넣으려고). 썸네일은 따로 작은 렌더러(240×180)로 찍는다.
