# 🧊 3D 집기 탭 (`page-floor`, `renderFloorPage`)

예전 이름 `3D 평면도`(2026-10-13, 채팅에서 만들어 GitHub에 올림) → **2026-10-14 영업2팀 요청으로 `3D 집기`로 바꾸고 넓혔다**.
코드는 `index.html` `</body>` 바로 앞 별도 `<script>` 블록, 탭 버튼 `#tab-floor`, 페이지 `#page-floor`(`page-lossreport` 앞). `switchTab`에서 `renderFloorPage()`. 팀 공유 DB는 쓰지 않는다(전부 이 브라우저 localStorage).

- 공간 가로×세로(mm)를 넣고 집기를 놓는다. 3D는 Three.js(cdnjs r128)를 탭을 열 때 불러온다.
- **① 집기 목록** — 집기마다 **그림**(3D 모양을 비스듬히 찍은 썸네일, `makeThumbs`) · **사이즈**(가로×깊이×높이 mm, 원형은 지름×높이 — 칸에서 바로 고침, `fpDim`) · **보유 수량** · 배치 수.
  체크한 집기만 평면도·자동 배치에 쓴다. 저장 `jvFloorUse`({on, qty, w, d, h}).
  기본 집기: 선반집기 이미지형 8 · 거울형 9 · 로고테이블 2 · 우양산 12(화이트샌즈 집기 목록 기준),
  카운터 1 · 스탠딩 거울 2 · **곡면 2단 진열대 2 · 원형 좌대 4**(매장 사진으로 잡은 추정값 — `(추정)` 표시).
  **+ 집기 직접 추가**: 이름 · 사각/원형 · 가로×깊이×높이 · 수량 → `jvFloorCustom`(지우기 버튼 있음).
- **② 예상 팝업 자리 이미지** — 올리면 긴 변 1600px JPEG로 줄여 `jvFloorPhoto`에 저장(새로고침해도 남음, 저장공간이 모자라면 그 세션만).
  `평면도·3D 바닥에 깔기`(`jvFloorOpt.photoFloor`)를 켜면 공간 가로×세로에 맞춰 늘려 깐다 — 몰 도면처럼 위에서 본 이미지일 때. 비스듬한 현장 사진은 끄고 참고로만 본다. 진하기 슬라이더.
- **자동 배치**(`fpAuto`) — `집기를 고르면 바로 자동 배치`(`jvFloorOpt.autoOn`, 기본 켬)가 켜져 있으면 체크·수량·사이즈·공간 크기를 바꿀 때마다 다시 배치한다.
  뒷줄 선반집기(이미지·거울형 번갈아) · 양옆 스탠딩 거울 · 가운데 줄(통로 900 뒤) · 앞 모서리 곡면 진열대(왼쪽 보통, 오른쪽 좌우반전) · 앞 가운데 원형 좌대(지그재그, 남으면 빈 자리).
  가운데 줄은 자리가 모자라면 **카운터 → 로고테이블 → 직접 추가 → 우양산** 순서로 남긴다(보유 12개인 우양산이 카운터를 밀어내지 않게), 놓는 순서는 로고테이블 · 직접 추가 · 우양산 · 카운터(오른쪽 끝).
  못 놓은 집기는 메시지에 '자리가 모자라 못 놓은 집기: …'로 적는다. 세로가 짧으면 곡면 진열대를 가운데 줄 양끝에 놓는다.
- **수동 이동** — 평면도에서 끌기(50mm 단위), **3D 화면에서 집기를 끌기**(바닥 평면에 레이캐스트, 빈 곳을 끌면 화면 회전, 빈 곳 클릭은 선택 해제),
  방향키(Shift 500mm) · R 회전 · Delete, 선택 칸의 회전 · 좌우반전(선반·곡면) · 복제 · 삭제 · 중심 X/Z 입력. 빨간색 = 겹침 또는 공간 밖.
  저장 배치를 불러오거나 `📷 샘플 매장 재현`을 누르면 그 배치를 지키려고 자동 배치를 끈다.
- **📷 샘플 매장 재현** — 2026-10-14 받은 매장 사진 4장 배치(6600×4600: 뒤 선반 3 · 로고테이블 2 + 카운터 · 거울 2 · 앞 곡면 2 · 좌대 4).
- **🖼 집기리스트 이미지**(`fpListPng`) — 3D 화면 + 체크한 집기의 그림 · 이름 · 사이즈 · 보유 · 배치 표를 1240px PNG 한 장으로 내려받는다. `🖼 3D 이미지 저장`은 3D 화면만.
- 저장·불러오기·삭제: 배치만(`jvFloorPlans`), 현재 배치는 `jvFloorCur`에 자동 저장.
- 좌표: x=오른쪽, z=아래(앞쪽 통로), 집기 중심 mm. rot 0=앞면 아래, 90=오른쪽, 180=위, 270=왼쪽.
- 3D 렌더러는 `preserveDrawingBuffer:true`(리스트 이미지에 화면을 그대로 넣으려고). 썸네일은 따로 작은 렌더러(240×180)로 찍는다.
