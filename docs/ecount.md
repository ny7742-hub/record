# 🧮 이카운트 탭 — 매장 발주(창고이동)

`page-ecount` · `tab-ecount` · `renderEcount` (2026-10-12 영업2팀 "매장은 창고이동, 매장에서 주문을 넣고 본사에서 승인").
이카운트 [재고Ⅰ › 기타이동 › 창고이동]의 '미확인 → 확인' 흐름을 자비스에서 먼저 돌리고, 결과를 엑셀로 이카운트·물류에 넘긴다.

- **① 발주 요청(누구나)**: 매장(`_ecStores` — `ORDER_STORES`에서 아난티·트래블메이트·백화점몰·CX 제외) + 상품 + 수량 → `ecSubmit`.
  **상품 검색은 수기발주와 같은 방식**(2026-10-13 영업2팀): `#ecSearch`에 상품명·칼라·자사코드 낱말 → 상품명 칩(`ecPickChip`)으로 좁히기 → 결과 클릭·↑↓·Enter(`ecAddResult`)로 담기, 수량 칸 비우면 1개. 결과 줄에 창고재고.
  검색칸·결과는 처음 한 번만 만들고(`#ecSr`) 담은 목록만 `#ecDraftBox`에 다시 그린다 — 다른 사람이 저장해 화면이 갱신돼도 입력이 안 날아가게.
  담을 때 주희물류 창고재고(`whQty`)를 보여 주고 `WH_MIN_ORDER` 이하면 경고만 한다.
- **저장**: 주문마다 `ws/ecOrders/{id}`에 **객체로** 따로 쓴다(`_ecPut`) — 여러 매장이 동시에 요청·승인해도 서로 덮지 않게(다른 팀 자료처럼 통째 문자열로 쓰지 않음).
  리스너는 `apply` 대신 직접 `on("value")` — 다 지워졌을 때도 비우려고. 필드: store·storeName·by·at·memo·state(요청/승인/반려/출고)·items[{code,name,qty,ok}]·okBy/okAt·reason·shipDate/shipBy/shipAt.
- **② 승인(관리자 `_authIsAdmin`, 승인제 전 `open`도)**: 요청 줄마다 승인 수량(`ok`) 조정 → `ecApprove` / `ecReject`(사유). 요청자·관리자는 요청 상태에서 취소(삭제). 관리자는 되돌리기(→ 요청).
  **본사 추가**(2026-10-12 영업2팀 "발주요청은 매장에서, 거기에 본사에서도 추가"): 요청·승인 상태 주문을 펼치면 관리자에게 `＋ 본사 추가` 칸(`ecAddTo`) —
  `{qty:0, ok:N, hq:true}`로 붙어 요청 칸에 '본사 추가'로 보이고 창고이동·도매발주서에 같이 나간다. 같은 상품이 있으면 승인 수량에 더한다. `ecDelHq`로 뺀다.
  탭 이름에 승인 대기 건수 `🧮 이카운트 (N)`.
- **③ 출고(관리자)**: 승인 주문을 체크 → 이동일자 →
  `⬇ 이카운트 창고이동 엑셀`(`이카운트_창고이동_YYYYMMDD.xlsx`, 열: 일자·순서·출고창고·입고창고·품목코드·품목명·수량·적요 — 같은 주문 = 같은 순서 = 전표 1장, 웹자료올리기에 붙여넣기) ·
  `⬇ 도매발주서(물류)`(`_wholesaleWorkbook`, 발주 메일과 같은 양식) → `✔ 출고 처리`.
- **창고코드(`ws/ecConfig` {hq, stores}, 관리자만)**: 본사 출고 창고 기본 **NH(주희창고)**(`_ecHq`, 2026-10-12 영업2팀). 매장 창고코드 = PlayMD 매장코드(영업2팀 확인 2026-10-12 — 이카운트 창고코드도 같다). 품목코드 = 자사코드 그대로.
- **아직 모르는 것**: 이카운트 웹자료올리기 실제 열 순서·창고코드·품목코드 규칙 — 이카운트 설정이 정해지면 `ecDlEcount`의 열과 코드 규칙을 맞출 것. 이카운트 Open API로 직접 저장하는 것은 하지 않았다.

## ↩ 매장 반품(2026-10-12 영업2팀 "이카운트 매장 반품등록")
- 같은 탭 위 **`📦 매장 발주 / ↩ 매장 반품`** 전환(`ecKind`, `_ecKind`). 화면·버튼 문구는 `EC_TXT[ord|ret]`. 담는 중인 목록은 종류별로 따로(`_ecDrafts`).
- 저장 `ws/ecReturns/{id}`(id `er…`, 발주는 `ec…` — `_ecPut`이 id 앞글자로 경로를 고른다). 흐름은 발주와 같다: 매장 반품 요청 → 본사 승인(수량 조정·본사 추가) → 입고 처리.
  상태값은 발주와 같은 문자열을 쓰고 '출고'만 화면에서 **입고**로 보인다(`_ecStLab`).
- 담을 때 **불량** 체크 → 줄에 `bad:true`. 창고이동 엑셀(`이카운트_창고이동_반품_YYYYMMDD.xlsx`)은 **매장 창고 → NH**, 불량 줄은 **→ 불량창고**(`ecConfig.bad`, 기본 `BAD` — PlayMD 불량창고와 같은 코드).
  받는 창고가 다르므로 한 반품 안에서도 정상·불량을 전표(순서 번호)로 나눈다. 반품에는 도매발주서가 없다.

## 📦 이카운트 창고재고(2026-10-13 영업2팀 "이카운트의 창고재고까지 보이게")
- 탭 위 보라 줄 `#ecStockBar` → **📤 이카운트 재고현황 올리기**(`ecStockLoad`, 누구나) → 팀 공유 `ws/ecStock` {at, by, file, n, how, wh:{창고:{품목코드:수량}}}. API 키 없이 엑셀로 받는다.
- 두 모양을 읽는다: ① 한 줄 = 창고·품목코드·재고수량(머리글에 '창고' 칸) ② 한 줄 = 품목, 창고마다 수량 칸(머리글 = 창고). 머리글 줄은 '품목코드'가 있는 줄(위 20줄 안). 합계·소계 줄·칸은 뺀다.
- 창고 맞추기 `_ecStockKey`: 코드 그대로 · '이름(코드)' · NH는 '주희' · 매장은 매장명(앞의 롯데백화점·롯데몰 등을 뗀 이름도). 품목은 자사코드(파일이 사이즈 뺀 코드여도 맞춤), 그 창고에 품목이 없으면 0.
- 보이는 곳(`_ecStock`·`_ecEcHtml`): **발주** = `PM n · 이카 n`(PlayMD 주희물류 · 이카운트 NH) — 검색 결과·담은 목록·승인 목록. **반품** = 정상/불량 + 고른 매장의 이카운트 재고.
- 하루(36시간) 넘은 자료면 줄에 '하루 넘게 지남'. 실제 이카운트 파일 모양을 받으면 파서를 다시 확인할 것.

## 📥 창고 재고 등록(2026-10-29 영업2팀 "이카운트 창고에 재고 등록할 수 있게" · "창고는 전체")
- 탭 위 전환 세 번째 **`📥 창고 재고 등록`**(`ecKind('stk')`, `EC_TXT.stk`). 이 모드에서는 ②·③ 카드(`#ecCard2`·`#ecCard3`)를 숨기고 ① 칸만 쓴다. 승인·팀 공유 없이 **엑셀만 만든다**.
- **창고 = 이카운트 창고 전체**: `EC_WHS`(영업2팀이 이카운트 [창고등록]에서 붙여 준 37곳 — 26SS·ALDAY·…·NH·NH3·NHJ·BAD·LJS·WD). 창고가 늘면 `EC_WHS`에 더한다.
  본사·불량 창고 설정(`_ecHq`·`_ecBad`)이 목록에 없는 코드면 앞에 붙이고, 이카운트 재고현황(`ws/ecStock`)에만 있는 창고도 붙인다(`_ecStkWhs`). 발주·반품의 매장 목록(`_ecStores`)과는 따로다.
- 한 목록에 여러 창고를 담는다 — 줄마다 `wh`(`{wh,code,name,qty}`, 같은 창고·품목은 하나로). 창고 순서대로 정렬(`_ecStkSave`), 위에 창고별 칩(줄·개수·`이카 자료 없음`·× 그 창고 비우기).
- 담기: 검색(고른 `담을 창고`로, 수량 0도 담김) · `📤 엑셀 불러오기`(`ecStkLoad`) · `📦 PlayMD 창고재고 그대로 담기(본사)`(`ecStkFromPM` — `_whFlat()` 주희물류 → 본사 창고, 같은 품목은 PlayMD 수량으로 바꿈). 표에서 수량 고침(`ecStkSet`). 목록은 이 PC `localStorage.ecStkDraft`에만.
- 엑셀 모양(머리글 줄 = `자사코드/품목코드/상품코드`가 있는 줄): ① `창고`(창고코드) 칸 + 수량 칸 ② 창고마다 수량 칸(머리글이 창고로 맞춰지는 칸) ③ 창고 칸이 없으면 고른 창고로(안 골랐으면 알림). 같은 창고·품목은 더한다.
  창고 글자 맞추기 `_ecStkWhOf`: 코드 · '이름(코드)' · 이름 그대로 · '주희'(불량·분리·일본 아니면 NH) · 이름이 들어간 글자. 못 맞춘 창고는 글자 그대로 담고 알림.
- `⬇ 이카운트 재고조정 엑셀`(`ecStkDl('adj')`, `이카운트_재고조정_{창고 또는 전체창고}_YYYYMMDD.xlsx`, 열: 일자·순서·창고·품목코드·품목명·수량·적요) — **창고마다 순서 번호 = 전표 1장**.
  담은 수량을 실재고로 보고 이카운트 재고와의 **차이만**(0은 뺌). `전수 실사` 체크면 담은 창고마다 이카운트에 재고가 있는데 안 담은 품목을 −로 0 맞춤. 이카운트 재고 자료가 없는 창고는 담은 수량 그대로 +(확인창).
- `⬇ 이카운트 기초재고 엑셀`(`ecStkDl('base')`, 열: 창고코드·품목코드·품목명·수량, 0 뺌) — 이카운트를 처음 쓰는 창고용.
- **아직 모르는 것**: 이카운트 재고조정·기초재고 웹자료올리기의 실제 열 순서 — 이카운트 화면의 양식과 다르면 `ecStkDl`의 열을 맞출 것.
