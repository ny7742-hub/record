# 🎬 모션 탭

`page-motion` · `tab-motion` (2026-10-12 영업2팀). 16:9 모션그래픽 「일이 완성되는 일곱 단계」 — 3D 카드 캐러셀.

- 카드 7장(기획·디자인·개발·테스트·배포·분석·개선)은 `MO_CARDS`에 있다: 제목 · 설명 · 배경 그라데이션 · 강조색 · SVG 아이콘(24×24 path).
- 무대는 1280×720 고정이고 `_moFit`이 화면 폭(전체화면이면 화면 크기)에 맞춰 줄이고 가운데에 둔다.
- 순서(`moPlay`): 0~1초 카드가 바닥에서 0.085초 간격으로 솟아 원을 이룬다 → 1초에 첫 카드가 정면 → 1.8초부터 0.8초마다 한 칸씩 돈다(`.mo-ring` 살짝 넘쳤다 서는 이징) → 6.6초에 개선.
  `반복 재생`을 켜 두면 7.1초에 흐려지고 7.6초에 처음부터 다시 돈다.
- 정면 카드: `.on`(1.15배 · 강조색 테두리 빛 · 설명 · 밑줄), 바닥 원·하단 진행 막대·오른쪽 위 번호가 그 카드 색으로 바뀐다.
  나머지는 정면에서 떨어진 각도만큼 어둡고 흐리게(`_moShow`의 brightness·saturate·blur).
- 회전 각은 `-k×(360/7)`로 계속 커진다 — 처음으로 되감기지 않게. 반사는 `-webkit-box-reflect`(크롬·엣지).
- 탭을 떠나면 `moStop`으로 타이머를 모두 끊는다.

- **손으로 넘기기**(2026-10-12 영업2팀 "마우스로 방향을 옮기거나 방향키로 전환"): `moGo(d)`·`moTap(i)` — 자동 재생을 멈추고(`moStop`, `_moManual`) 한 칸씩 돈다.
  ← → (↑↓도) 방향키 · Home/End(처음·마지막) · 무대에서 좌우로 끌기(80px마다 한 칸, 왼쪽으로 끌면 다음) · 휠(0.35초에 한 칸) · 카드나 아래 단계 표시 누르기(가까운 쪽으로 돈다).
  지금 몇 칸인지는 `_moK`(음수도 됨 — `_moShow`가 양수로 맞춤). `▶ 처음부터`를 누르면 다시 자동 재생. 입력칸에 글을 쓰는 중이면 방향키는 건드리지 않는다.
