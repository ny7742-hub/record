## 로그인 · 바로가기 (2026-10-15)
- 자동화 창 두 개에 계정 하나씩 — 지금은 **첫 창(9333) = 블랙샌즈 · 두 번째 창(9334) = 화이트샌즈**. 계정은 화면 위 업체 이름으로 가른다
  (`(주)엔에이치그룹_블랙샌즈` = 블랙샌즈, `(주)엔에이치그룹` = 화이트샌즈) — 창을 바꿔 로그인해도 이름은 맞게 나온다.
- `automation/portal-open.mjs` `cp`(첫 창) · `cp2`(두 번째 창), `portal-status.mjs` `cp1` · `cp2`(who = 업체 이름), saip-watch `needLogin` 키 `cp1`·`cp2`.
- 자비스 로그인 상태 `쿠팡(화이트샌즈)` · `쿠팡(블랙샌즈)`, 바로가기 칩 같은 이름(자동화 창 모드면 그 창에 연다).

## 발주건 확인 (2026-10-15)
- `automation/coupang-po-check.mjs` — 두 창의 쿠팡 탭 안에서 `GET /po-web/app/purchase-order/list?searchDateType=WAREHOUSING_PLAN_DATE&searchStartDate&searchEndDate&purchaseOrderStatus=RP&page`
  (RP = 거래처확인요청 = 아직 확인 안 한 새 발주, 입고예정일 2주 전 ~ 45일 뒤, 쪽마다). **보기만** — 쿠팡 화면은 누르지 않는다.
  날짜는 UTC로 온다(`2026-10-19T15:00Z` = 10/20). 결과 `ws/cpOrderReady {at, by, total, accounts:[{port, who, n, qty, amt, list:[{seq, center, date, qty, amt, sku}]}]}`.
- saip-watch `cpCheckTick` — **평일 10:00 · 16:00**(칸 안 50분, 돈 칸 `logs/cp-check-날짜`) + 자비스 `🔢 발주건 확인` → `ws/cpCountReq`(5분 넘으면 버림).
- 자비스 쿠팡 카드 맨 위 `📦 새 발주(거래처확인요청) N건` — 계정마다 건수·수량·금액, 펼치면 입고예정일별(센터).
- 상태 코드: RP 거래처확인요청 · MP 거래처수정 · PA 발주확정 · RI 거래명세서확인요청 · CI 거래명세서확인.
- 발주서 가공 참고 파일: `화이트샌즈(1014) - 쿠팡 (10월20일 입고예정일).xlsx` — `상품정보(1)` 탭 = PO 칸(발주번호·SKU 이름·SKU Barcode·물류센터·입고예정일·발주수량·확정수량·매입가…),
  `발주서` 탭 = 만들 쿠팡 발주서(24칸), `배송지` 탭 = 물류센터 → 주소·연락처, `상품코드` 탭 = 상품코드표.

## PO → 쿠팡 발주서 (2026-10-15)
- 발주건 확인 때 거래처확인요청 발주마다 **상세 화면** `/scm/purchase/order/get/{발주번호}`(서버 HTML)를 탭 안 fetch + DOMParser로 읽어
  `list[].lines = [{sku(SKU ID), bar(880 바코드), name, qty(발주수량), able(업체납품가능수량), price(매입가)}]` · `addr`(쿠팡 입고 주소)를 같이 올린다.
  첫 창 탭이 뒤에 깔려 있으면 느리다(목록 한 번에 30초) — `evalIn` 기다림 240초.
- 자비스 쿠팡 카드 `📄 M/D 발주서 N건 N개`(입고예정일마다) → `cpMakeSheet(date)` → **계정마다 파일 하나 — `화이트샌즈(오늘MMDD) - 쿠팡.xlsx` · `블랙샌즈(오늘MMDD) - 쿠팡.xlsx`**(2026-10-15 영업2팀 "파일명으로 구분"), 시트 `발주서` 24칸(예시 파일과 같은 머리).
  C 발주번호 · D 쿠팡 · E 물류센터 · H/J 연락처·주소(`CP_CENTERS` = 예시 파일 배송지 탭 49곳, 없으면 쿠팡 입고 주소) · L 상품명 = 큐텐명 + 바코드 ·
  M 발주수량 · N 매입가 · O SKU 이름 · P 바코드 · Q 큐텐바코드 = T 상품컬러코드(자비스 상품데이터 바코드1·2 → 자사코드) · R 상품코드.
  A = **입고일**(입고예정일 YYYYMMDD) — 두 계정 다(영업2팀 "10/20일 입고일" — 문서의 '출고일 칸에 블랙샌즈'는 쓰지 않는다). 바코드를 못 찾은 줄은 Q·R·T 빈칸 + 알림.
- 검증(2026-10-15): 10/20 입고예정 화이트샌즈 5건 41줄 543개가 예시 파일 `발주서` 탭과 발주번호·센터·수량·매입가·상품명·바코드·큐텐바코드 전부 같음.
- 수량은 아침 기준 **발주수량** — 오후 미출고 반영·확정수량은 아직(2단계).

## 자동으로 하려면 필요한 것(아직 없음)
- (받음) 쿠팡 발주서 양식 · 배송지 표 — 위 참고 파일.
- (됨) 코드매칭: 자비스 상품데이터 바코드1·2(880…) → 자사코드로 찾는다(코드매칭 시트 없이).
- (됨) 서플라이어 허브 두 계정 로그인 — 자동화 창 두 개(비밀번호는 다루지 않는다).
- 발주 확정 업로드 · 쉽먼트 일괄 등록은 되돌리기 어렵다 — 자동으로 하더라도 미리보기 뒤 사람이 누르게.
