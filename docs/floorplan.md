# 🧊 3D 집기 탭 (`page-floor`, `renderFloorPage`)

예전 이름 `3D 평면도`(2026-10-13, 채팅에서 만들어 GitHub에 올림) → **2026-10-14 영업2팀 요청으로 `3D 집기`로 바꾸고 넓혔다**.
코드는 `index.html` `</body>` 바로 앞 별도 `<script>` 블록, 탭 버튼 `#tab-floor`, 페이지 `#page-floor`(`page-lossreport` 앞). `switchTab`에서 `renderFloorPage()`. **팀 공유**(2026-10-14 영업2팀): Firebase `ws/fx3d` — `cur`(현재 배치) · `plans`(저장한 배치) · `use`(체크·수량·사이즈) · `cus`(직접 추가·사진 집기) ·
`img/<키>`(사진 집기 그림) · `photo`(예상 팝업 자리 이미지) · `meta`(마지막 배치 수정 사람·시각, 화면 `#fpShare`). localStorage는 같은 키로 사본을 둔다.
'바로 자동 배치'·바닥 진하기(`jvFloorOpt`)만 각자. 쓰기는 모아서(배치 0.5초) 한 번에, 되돌아온 내 값은 건너뜀(`SH.last`), 남의 배치는 끄는 중이면 버리고 내 것을 올린다(마지막에 쓴 사람이 이긴다).
탭을 처음 열 때 공유본(`cur`)이 비어 있으면 이 브라우저 것을 올려 시작(`startShare`). localhost·승인 전 사용자는 공유 안 함(다른 탭과 같은 규칙, 3초마다 다시 봄).

- **바닥 칸 = 600mm(60cm)**(2026-10-21 영업2팀, 예전 500mm): 평면도 회색 줄(`draw2d` `v+=600`)과 3D 바닥 줄(`rebuild3d` `i+=0.6`) — 3D 집기 · 3D 집기2 둘 다. 옮길 때 눈금(`SNAP` 50mm)·Shift 이동(500mm)은 그대로.
- **화면 배치**(2026-10-14 영업2팀): 위 = ① 평면도(1칸) · ② 3D 보기(2칸, 높이 600px) / 아래 = ③ 집기 수량 표(+ 직접 추가 · 사진으로 만들기) · ④ 예상 팝업 자리 이미지(오른쪽).
